# تحديث بيانات الخريطة من Excel

تعمل أداة الاستيراد محليًا على جهاز مخوّل، وتنتج البيانات العامة التي تقرؤها الخريطة
الحالية. لا ترفع ملف Excel إلى الموقع أو GitHub. يبقى المصدر خارج مجلد المستودع.

## التجهيز مرة واحدة

يلزم Python 3.10 أو أحدث. من مجلد المشروع:

```sh
python -m venv .venv
```

فعّل البيئة في Windows PowerShell بالأمر `.venv\Scripts\Activate.ps1`،
أو في macOS/Linux بالأمر `source .venv/bin/activate`، ثم:

```sh
python -m pip install -r requirements-import.txt
python -m unittest discover -s tests -v
```

## عند وصول نسخة جديدة

1. تحقق من مصدر النسخة وتاريخها مع مسؤول البيانات، واحفظها خارج المستودع.
2. شغّل المعاينة مع استبدال المسار بمسار الملف الحقيقي:

```sh
python tools/import_facilities.py "C:/private/facilities-new.xlsx"
```

3. افتح `build/import-review/report.json`. راجع العدد السابق والجديد، والأعداد حسب
   المحافظة والبرنامج، والمواقع المنشورة والمخفية، وعدد الإضافات والحذف والحقول
   المعدلة. التقرير لا يعرض أسماء المنشآت أو معرّفاتها أو الإحداثيات.
4. إذا ظهر `blocked`، أصلح السبب في المصدر وأعد المعاينة. لا تتغير بيانات الموقع
   عند فشل التحقق، وتُحذف المعاينة القديمة لتجنب استخدامها بالخطأ.
5. بعد مراجعة الملف العام الناتج والموافقة على نشره، انسخ قيمة `approval_token`:

```sh
python tools/import_facilities.py "C:/private/facilities-new.xlsx" --apply --approve "TOKEN_FROM_REPORT"
```

يُستبدل `assets/facilities-data.js` تلقائيًا؛ لا حاجة لتعديل سجلات JavaScript يدويًا.
يلزم تقرير جديد إذا تغيرت البيانات العامة أو سياسة النشر أو النسخة السابقة.
الرمز يحمي من تطبيق معاينة قديمة، ولا يمثل نظام تسجيل دخول أو موافقة مؤسسية.

6. افتح `index.html` وافحص العلامات والفلاتر والدليل والتكبير. راجع التغييرات ثم
   ارفع الملف العام فقط عبر طلب دمج. لا ترفق Excel أو النسخة الداخلية. يمكن الرجوع
   إلى آخر نسخة عامة معتمدة من Git عند الحاجة.

## قواعد أساسية

- تُقرأ أوراق Lattakia وTartous وHama وHoms فقط. أوراق التجميع المعروفة لا تدخل في العد.
- تتحقق الأداة من أسماء الأعمدة حتى لو تغير ترتيبها، وترفض الصفوف الناقصة والتكرار
  وصيغ Excel داخل البيانات. عمود الترقيم غير المستخدم مستثنى ولا تُقيَّم صِيَغه.
- تقبل الإحداثيات العشرية وDMS، وترفض القيم غير الصالحة. حدود سوريا المستخدمة
  فحص أولي فقط؛ لا تثبت وجود النقطة على اليابسة أو صحة موقعها ميدانيًا.
- يبقى تصحيحا تبديل الإحداثيات السابقان معلَّمين للتحقق، ولا يجري تخمين تبديلات جديدة.
- تُخفى كل خدمات GBV والحماية حتى لو كان البرنامج مكتوبًا RH. تُخفى المنشآت الجديدة
  افتراضيًا، وتبقى ضمن العد دون علامة جغرافية.
- لنشر منشأة جديدة غير محمية، يلزم اعتماد نشر تفاصيلها وإضافة رمزها فقط إلى
  `tools/public-policy.json` ثم إعادة المعاينة. لا تُضاف رموز المنشآت المحمية إلى هذا الملف.
- إذا أصبحت منشأة منشورة خدمة حماية، احذف رمزها من قائمة السماح ضمن المراجعة نفسها.
- التقرير يقارن المنشآت المحمية بالأعداد الإجمالية فقط، لأن البيانات العامة القديمة
  لا تحتوي على هوياتها أو تفاصيلها. مراجعة تغيراتها الفردية تبقى لدى مسؤول البيانات.

اختُبرت الأداة على الملف الأصلي المرفوع في 13 أكتوبر 2026، وليس على نسخة أحدث مفترضة.
عدد سجلاته 51. السياسة الجديدة تُخفي 18 سجلًا بدل 17 لأن أحد سجلات RH من نوع
«مساحة آمنة للنساء والفتيات». هذا تغيير في سياسة الحماية، وليس وصول منشأة جديدة.

التفاصيل الكاملة لأسماء الأعمدة وأكواد الأخطاء والاختبارات:
[UPDATING_DATA.md](UPDATING_DATA.md).

هذا التعديل يضيف الأداة والاختبارات فقط، ولا يستبدل لقطة البيانات المنشورة حاليًا.
قائمة السماح الإضافية فارغة؛ تحتفظ الأداة باعتماد المنشآت العامة غير المحمية الموجودة
في النسخة السابقة. رفع لقطة جديدة يحتاج إلى مراجعة واعتماد النشر منفصلًا.
